Para poder utilizar esquemas con proyectos de Angular necesitas instalar el paquete `@schematics/angular`

```bash
npm i @schematics/angular
```

Y en nuestro esquema de `http-resource` vamos a agregar estas 2 propiedades nuevas.
```ts
  path: string;
  project: string;
```

Y de la misma manera le actualizaremos al `schema.json`
```json
"path": {
    "type": "string",
    "format": "path",
    "description": "The path at which to create the service, relative to the workspace root.",
    "visible": false
},
"project": {
    "type": "string",
    "description": "The name of the project.",
    "$default": {
        "$source": "projectName"
    }
}
```
