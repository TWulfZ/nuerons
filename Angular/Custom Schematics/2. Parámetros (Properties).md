Para generar archivos de forma dinámica con cosas custom vamos a crear los parámetros en nuestro esquema.

Crearemos en el esquema greeter en la carpeta de `src/greeter` los archivos de:

`schema.d.ts`
```ts
export interface Schema{
    name:string
}
```

`schema.json`
```json
{
    "$schema": "http://json-schema.org/schema",
    "$id": "GreeterSchema",
    "title": "Greeter Schema",
    "type": "object",
    "description": "Print a personalized greet message",
    "properties": {
        "name": {
            "type": "string",
            "description": "Name of the person you want to greet",
            "$default": {
                "$source": "argv",
                "index": 0
            },
            "x-prompt": "Ingresa el nombre del módulo:",
        }
    },
    "required": [
        "name"
    ]
}
```

> [!Notes] Notas
>
> - Con el `default index 0` permitiremos que se tome por argumentos la cadena que se pase después del comando.
> - Con el `x-prompt` vamos a permitir mostrar un input para que el usuario muestre en caso de no pasar los parámetros.

Y fuera en la colección vamos agregar el esquema `.json` a la colección.
`collection.json`
```json
"greeter": {
    "description": "A blank schematic.",
    "factory": "./greeter/index#greeter",
    "schema": "./greeter/schema.json" // <--Aquí--
}
```

Y solo nos falta decirle a nuestro `factory` que hacer con esos parámetros.
Actualizamos las `_options` para utilizar el `./schema.d.ts` que creamos para que tengamos tipado los parámetros que le pasamos a nuestro esquema.
`src/greeter/index.ts`
```ts
import { Rule, SchematicContext, Tree } from '@angular-devkit/schematics';
import { Schema } from './schema';

export function greeter(_options: Schema): Rule {
    return (tree: Tree, _context: SchematicContext) => {
        let name = _options.name;
        if(tree.exists('hello.js')){
            tree.delete('hello.js');
        }
        tree.create('hello.js', `console.log('Hello ${name}')`);
        return tree;
    };
}
```

Y ejecutamos el `schematic` seguido del parámetro
```
schematics .:greeter demouser --dry-run false
```
> [!WARNING] Asegúrate que el `hello.js` este eliminado

> [!INFO] Tambien puedes ejecutarlo desde su nombre como `--name=demouser`
