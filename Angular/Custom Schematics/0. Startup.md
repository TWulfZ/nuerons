Guía completa [https://github.com/sonusathyadas/angular-schematics]

Para crear nuestros esquemas customs, vamos a generar un proyecto sin aplicación.

##### 1. Para generar el proyecto
```powershell
schematics blank sample-schematics
```

En el `/src` se nos generara una carpeta de esquemas, donde el `collection.json` va agrupar todos los comandos de nuestros esquema (las carpetas que se van creando). Y tendremos este contenido.
- `package.json`
- `tsconfig.json`
- `src\collection.json`
- `src\sample-schematics\index.ts`
- `src\sample-schematics\index.spec.ts`
##### 2. Activar modo Watch para mejor desarrollo
En el `package.json`
```json
"scripts": {
    "build": "tsc -p tsconfig.json",
    "build:watch": "tsc -p tsconfig.json --watch",
    "test": "npm run build && jasmine src/**/*_spec.js"
},```

##### 3. Probamos el esquema
Corremos el build en modo Watch para desarrollar en tiempo real.
```powershel
npm run build:watch
```

Y corremos el esquema compilado
```
schematics .:sample-schematics
```
> [!Notes] Notas
>- El punto hace referencia al paquete actual que estamos ejecutando, cuando lo ejecutemos en un proyecto de Angular real, tendremos que hacer referencia al nombre del paquete que tiene en el `package.json`
>- El factory del esquema ejecuta el nombre de la función según esta definido en el `collection.json` 
>  ```json
>// src/collection.json
>	"factory": "./greeter/index#greeter",
>```
>```ts  ↑
> // src/greeter/index.ts   ↑
>	export function greeter(_options: any): Rule { // ...
>```
