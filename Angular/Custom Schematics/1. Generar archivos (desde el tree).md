Vamos agregar un nueva esquema a la colección para generar un archivo `hello.js`
```
schematics blank greeter
```

Entonces en su carpeta vamos a encontrar la función
```ts
// src/greeter/index.ts
export function greeter(_options: any): Rule {
    return (tree: Tree, _context: SchematicContext) => {
        tree.create('hello.js', `console.log('Hello User')`);
        return tree;
    };
}```

Ejecutamos
```
schematics .:greeter
```

Y nos mostrara el output pero no generara archivos, por estar en modo desarrollo deberemos poner `--dry-run false` para que genere los archivos en el `:root`. 
```powershell
schematics .:greeter --dry-run false
```

Y veremos el archivo `hello.js` en nuestro proyecto.
