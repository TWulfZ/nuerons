Ahora vamos a generar los archivos desde el generador de archivos con templates en EJS, del cual vamos a utilizar las librerías de `strings` para manipular texto según el formato que necesitemos.
![[Pasted image 20251105140500.png]]
Para transformar por ejemplo el nombre mi archivo sale de `MyDemo` y lo formateamos con `dasherize` para tener el nombre `my-demo`, pero en la función queremos pasarlo con `camelize` para obtener `myDemo`.

Para lograr este comportamiento en los archivos crearemos un archivo denominado `__name@dasherize__.js`. Y para interpolar datos usaremos los operadores:
- `<%` `%>` :  Para ejecutar código
- `<%=` `%>`: Para imprimir valores ( `<%= variable %>`) 

Entonces crearemos dentro de la carpeta del esquema `greeter` una carpeta `/files`
```
    src
     |_ greeter
          |_ files
               |_ __name@dasherize__
                      |_ __name@dasherize__.hello.js   
```
`__name@dasherize__.js`
```js
	console.log(`Hello <%= dasherize(name) %>`)
```

Entonces vamos a nuestro factory `greeter/index.ts`
```ts
import { strings } from '@angular-devkit/core';
import { apply, Rule, SchematicContext, Tree, url, template, mergeWith } from '@angular-devkit/schematics';
import { Schema } from './schema';

export function hello(_options: Schema): Rule {
    return (tree: Tree, _context: SchematicContext) => {

        const sourceTemplate = url("./files");
        const parameterizedTemplate = apply(sourceTemplate,[
            template({
                ..._options,
                ...strings
            })
        ]);
        tree = mergeWith(parameterizedTemplate)(tree,_context) as Tree;
        return tree;
    };
}
```
Donde vamos a traer la template con el `url("./files")` y aplicamos las transformaciones (rules) del `template` pasándole las `...options` y `...strings`, finalmente lo mandamos a construir al arbol.
